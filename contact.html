문의 양식

GitHub 이슈로 접수

버튼을 누르면 작성한 내용이 채워진 GitHub 이슈 작성 화면이 새 창으로 열립니다. GitHub 계정으로 로그인한 뒤 'Submit new issue'를 눌러 주세요.

접수는 이렇게 진행됩니다

  1. 위 양식을 작성하고 버튼을 누릅니다.
  2. 내용이 미리 채워진 GitHub 이슈 화면이 열립니다. GitHub 계정이 없다면 무료로 만들 수 있습니다.
  3. 'Submit new issue'를 누르면 접수가 완료됩니다.
  4. 영업일 3일 이내에 확인하고, 수정이 필요하면 페이지에 반영한 뒤 이슈에 회신합니다.

오류 제보 시 함께 알려 주시면 좋은 것

  • 이용한 계산기 이름과 페이지 주소
  • 입력한 값 (연봉, 부양가족 수, 대출금액, 금리, 기간 등)
  • 계산기에 표시된 결과와, 예상한 결과
  • 근거가 되는 법령·공고·공단 안내 링크
  • 사용 중인 브라우저와 기기 (화면이 깨지는 경우)

제휴·광고 문의

제휴나 광고를 문의하실 때는 제안 내용, 게재 위치, 기간, 비용 조건을 함께 적어 주세요. 다만 다음 조건은 받지 않습니다.

  • 계산 결과나 평가를 광고주 요청에 따라 바꾸는 제안
  • 확인되지 않은 효능·수익을 보장하는 문구의 게재
  • 금융상품·투자 권유를 계산기 콘텐츠와 구분 없이 섞는 형태

개인정보를 적지 마세요

문의는 공개 게시판에 남습니다. 주민등록번호, 계좌번호, 카드번호, 전화번호, 상세 주소, 타인의 개인정보는 절대 적지 마세요. 개인정보가 포함된 문의는 운영자가 임의로 가릴 수 있으며, 개인정보처리방침에 처리 기준을 안내하고 있습니다.

다른 문의 경로

사이트의 모든 콘텐츠는 공개 저장소에 있습니다. 계산식이나 문구의 오류를 직접 지적하고 싶다면 저장소의 Issues에서도 확인할 수 있습니다. 사이트 운영자는 개별 이메일 주소나 전화번호를 공개하지 않으며, 문의는 이 페이지를 통해서만 받습니다.
